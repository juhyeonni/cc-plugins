# cc-plugins

My personal [Claude Code](https://docs.claude.com/en/docs/claude-code/overview)
plugin marketplace — skills and agents I build to work more efficiently. Add the
marketplace once, then browse and install from `/plugin`.

## Before you start

- **Claude Code** must be installed (see the [docs](https://docs.claude.com/en/docs/claude-code/overview)).
  The commands below are typed directly into a Claude Code session prompt.
- Some plugins need extra tools to run (see the "Requirements" column below).

## Setup

Run once inside a Claude Code session:

```
/plugin marketplace add juhyeonni/cc-plugins
```

After that, manage everything from `/plugin` (list / install / update).
