# Missing inputs warn and record a skipped label

Status: Accepted

A missing input warns, asks, and on proceed records a `skipped:*` label. It never blocks.

Why: GitHub Free private repos cannot enforce server-side gates, and the label lets skipped stages be counted.

Source: #1 D3 (https://github.com/juhyeonni/cc-plugins/issues/1#issuecomment-5971085521)
