# A spec or verdict needs its marker and a trusted author

Status: Accepted

A comment is a spec or a verdict only when its body starts with the marker and a trusted author wrote it. A marker quoted further down counts for nothing.

Why: the spec is the one contract per Issue (#1 D4), and any login can write a marker (#44 D2); trusted means by login (#13 D2).

Source: #1 D4, and the Lookup section of the body of #1 for the first-line rule (https://github.com/juhyeonni/cc-plugins/issues/1#issuecomment-5971085521)
