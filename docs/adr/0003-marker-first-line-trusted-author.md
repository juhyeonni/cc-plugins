# A spec or verdict needs its marker and a trusted author

Status: Accepted

A comment is a spec or a verdict only when its body starts with the marker and a trusted author wrote it. A marker quoted further down counts for nothing.

Why: the spec is the one contract per Issue, and any login can write a marker.

Source: #1 D4 and Details decided (https://github.com/juhyeonni/cc-plugins/issues/1#issuecomment-5971085521)
