# Posted means the POST printed its id

Status: Accepted

A comment, Issue or PR counts as posted only when the POST printed its id. Never confirm a post by finding a comment that starts with a marker.

Why: verify found an untrusted author's fake marker comment and reported its refused verdict as posted.

Source: #44 D2 (https://github.com/juhyeonni/cc-plugins/issues/44#issuecomment-5979057605)
