# PRs open as drafts and a person merges

Status: Accepted

`open-pr` opens every PR as a draft. A person marks it ready after reading the verdict, then merges. No skill turns a draft ready.

Why: a draft cannot be merged before `verify` has posted, and marking ready exists only in GraphQL.

Source: #25 D1, D6 (https://github.com/juhyeonni/cc-plugins/issues/25#issuecomment-5990198315), shipped in PR #99
